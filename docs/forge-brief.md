## 项目概述

- **项目名**：Comedot（`config/name: "Comedot"`，`Game/override.cfg` 覆盖为 `"Comedot Example"`）
- **仓库**：`Comedot_GDGameProjZero`（fork：`git@github.com:yzx4036/comedot.git`，分支 `develop`，含上游 `up_stream` 定期合并）
- **本质**：**Godot 2D 游戏组件框架 + 项目模板**（"opinionated as fuck framework"），非完整游戏。由 InvadingOctopus 的开源 Comedot 框架[^1]派生，本 fork 增加了：
  - Luban 配置表管线（C# 生成 + GDScript 桥接）
  - Godot MCP 自动化回归闭环
  - `Game/` 子树作为独立业务仓挂载点（当前仅承载最小闭环示例）
- **仓库边界**：`Game/` 之外为框架层；`Game/` 为业务层，由 `AGENTS.override.md` 单独约束，`.gitignore` 忽略 `Game/*`（业务代码不入框架仓；历史业务 `Cd_ProjectZero` 已迁移至 `Comedot_GDGameProjWuXia`）。

| 项 | 值 |

## 平台目标

- **实际运行目标**：桌面（Windows 本机验证 + Godot MCP headless 自动化）；模板本身跨平台。
- **窗口管理**：`GlobalUI.setWindowSize()` 维持最小尺寸、HiDPI 补偿；快捷键 `windowResizeTo720/1080`、`windowToggleAlwaysOnTop`。
- 无移动端/网页端专项配置（`window/stretch` 整数像素缩放对低分率 2D 目标友好，未声明导出预设——`export_presets.cfg` 被 gitignore）。

## 核心玩法

- **框架层**：无玩法。提供 120+ 组件、实体模板、UI 控件、工具脚本，覆盖横版/俯视/滚动/滑块/回合制/网格/能力/战斗/收集/交互/升级等子系统。
- **`Game/` 层（当前）**：**Comedot 框架闭环示例** `res://Game/Example/ExampleScene.tscn` —— 玩家（模板 `PlayerEntityTemplate-Platformer` + `CollectorComponent`）向右走过 3 颗宝珠，`CollectibleComponent` + `ExampleGemPayload` 触发收集，HUD 计数。
  - 该示例不含业务代码，作为框架回归载体，供 godot-mcp 自动化核对（标记：`EXAMPLE_READY` → `EXAMPLE_COLLECT 1/3..3/3` → `EXAMPLE_DONE`）。
- 前身业务（武侠 `Cd_ProjectZero`）：已整体迁出，不在本仓。

## 关键入口

- `project.godot` 默认主场景：`Scenes/Launch/Logo/IOLogoScene.tscn`（LOGO → `GameFrame.tscn` 主菜单）
- `Game/override.cfg` 覆盖主场景 → `res://Game/Example/ExampleScene.tscn`（示例即插即玩）
- AutoLoad 顺序（项目实际）：`Global → Settings → Debug → SceneManager → GlobalInput → GameState → GlobalUI → GlobalSonic → TurnBasedCoordinator`

## 依赖

- 无第三方包运行时依赖（非 NuGet 外部包；`Comedot.csproj` 无 PackageReference）。
- 工具链依赖：`dotnet`（Luban DLL 执行）、`godot` CLI（`GODOT` 环境变量）、`godot-mcp` CLI（自动化）。
- 外部内容：Kenney 1-Bit 图集（CC0 风格授权）、PixelOperator 字体（免费商用）。
